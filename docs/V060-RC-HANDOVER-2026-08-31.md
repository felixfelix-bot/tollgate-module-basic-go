## 5. Step 3 — Race-test gate (owned by Felix's agents)

```bash
cd src/
go test -race -count=1 -tags testenv ./...
```

- Run **2–3 full iterations** on fresh `origin/main` (post step-1 merges).
- Known flake candidates: `time.Sleep`-based tests in `merchant/` and `wgm/` packages.
- Policy: root-cause before touching; fix only unambiguous nondeterminism (sleep→poll) with test-only changes; ambiguous flakes get documented, not "fixed" blindly.
- Gate: release is blocked until the suite is green across consecutive full runs.

## 6. Step 4 — Tag protocol (⚠️ read carefully, agents)

**HAZARD:** on the upstream repo, any pushed tag matching `^v\d+\.\d+\.\d+$` triggers `build-package.yml` → **one-shot Nostr-wide stable publish** (5 blossom servers, kind-1063, **unretractable, no draft stage**).

Rules:
- Tag push is **Felix, manual, once** — no agent ever pushes a version tag.
- Never `git push --tags`. Push a single explicit tag only: `git push <remote> v0.6.0`.
- Some local checkouts carry stray audit tags (`v0.6.0` local-only, `v0.6.1-post-merge`, `v0.7.0-alpha9/10`) — these must never reach upstream.
- Verify `build-package.yml` on `main` is the post-#369/#370 version before tagging (so the artifact build uses the fixed pipeline).
